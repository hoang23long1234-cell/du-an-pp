# Môi Trường API

Thư mục này chứa toàn bộ các khóa API và cấu hình bảo mật của dự án (từ A-Z).
**LƯU Ý QUAN TRỌNG:** 
1. Không bao giờ commit file `.env` lên Github hoặc chia sẻ công khai.
2. File `.env` đã được bảo vệ bởi `.gitignore` trong thư mục này.
3. Nếu thêm khóa API mới, hãy thêm cấu trúc mẫu vào file `.env.example`.
